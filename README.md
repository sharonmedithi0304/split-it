# Split-It — Settle Up Smart

A smart expense splitter for friend groups that calculates the minimum number of transactions needed to settle all debts.

## 🔗 Live Demo
https://sharonmedithi0304.github.io/split-it

## ✨ Features
- Add friends with colored avatars
- Log expenses by category (Food, Transport, Entertainment, etc.)
- Automatically calculates who owes who
- Minimum Transactions Algorithm to settle debts efficiently
- One-click mark as done for settlements
- Data saved with localStorage

## 🛠️ Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Minimum Transactions Greedy Algorithm
- localStorage

## 🚀 How to Run Locally
1. Clone the repo
   git clone https://github.com/sharonmedithi0304/split-it.git
2. Open index.html in your browser
